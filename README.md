# Obzue Desk v0.1

Browser desk for ObzueAI Maker work. Free MIT. Not Windows. Not Paperclip. Not Corta.

**Offer:** open the desk, add a Binder ticket, export `board.json`.

Repo: https://github.com/obzue/Obzue-Desk

## Screenshot

See `docs/SCREENSHOT.md`. Wallpaper and PNG icons are in `desktop/` and `desktop/assets/`.

## 60-second demo

```bash
python3 -m http.server 8080 --directory desktop
```

Open http://127.0.0.1:8080 — taskbar should read v0.1.0. Open Binder, Add, Export.

## Layout

- `desktop/` — UI plus start-icon.png volume-icon.png logo.png wallpaper.png
- `desktop/assets/` — full PNG set
- `docs/screenshot.png` — capture
- `skills/` — Binder and product-forge
